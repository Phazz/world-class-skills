# Communicate: make the hard fact or the real progress easy to act on

Pick the lens that matches the artifact, read its file, and apply it. Say which you used.

| Signal in the request | Lens |
| --- | --- |
| Weekly update, 5-15, status report, progress summary, stakeholder update | [Weekly update](references/weekly-update.md) |
| Feedback, disagreement, request, refusal, apology, relationship repair, preparing a difficult conversation | [Cooperative conversations](references/cooperative-conversations.md) |

For writing requests, return the usable draft first and keep any explanation brief.

## Boundaries

- Every claim must match the supplied evidence; label missing owners, dates, or numbers instead of inventing them.
- Keep the difficult fact or request explicit; tact must not hide it.
- Drafting does not authorize sending or publishing.
