# Review modes

- **Intake:** test a new proposal against strategy, available resources, and alternatives.
- **Weekly health:** inspect changes, milestones, risks, and decisions needed; avoid reopening everything.
- **Monthly allocation:** reassess remaining value, exposure, and capacity across all active initiatives.
- **Quarterly strategy:** revisit assumptions, portfolio composition, and objectives.
- **Exception:** investigate a breached, previously agreed threshold or material new evidence.

For unattended reviews, use a defined evidence cutoff, bounded source scope, and a run identifier. Report unavailable or stale inputs explicitly. Do not silently reuse old data as current or duplicate a previous decision on retry. If nothing material changed, return a short no-change result.
